# ViewScope 1.3.0

- 新增 iOS 宿主支持：可调试 iOS / iPadOS 模拟器中的 App，以及通过 USB（usbmuxd 隧道）连接的真机；宿主端重构为共享核心 + AppKit / UIKit 双平台实现。
- 新增测量与取色、布局问题诊断、修改记录（⌘Z / ⇧⌘Z 撤销重做、逐条还原、导出 Swift 代码）、抓取对比，调试控制台支持带参数方法、key path、对象引用、历史与自动补全。
- 连接协议升级到 v3：端口段发现、逐连接认证、版本协商、请求超时、断线后自动重连；宿主侧 ViewScopeServer 需同步升级到 1.3.0。
- 全新界面与应用图标：工具栏并入标题栏，面板改为统一的圆角卡片，预览工具栏按功能分组，偏好设置改为系统设置风格。
- 修复数值越界、私有 KVC、自动刷新覆盖选中、Inspector 写错节点、编辑中被刷新提交等多处会导致崩溃或误操作的问题。
